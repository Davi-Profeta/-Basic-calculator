# Basic-calculator
Uma aplicação web de calculadora simples, intuitiva e totalmente responsiva, focada na manipulação dinâmica do DOM e estilização com CSS moderno.

---

## 📌 Funcionalidades

- [x] **Operações Matemáticas:** Suporte para adição (`+`), subtração (`-`), multiplicação (`x`) e divisão (`/`).
- [x] **Limpeza de Tela:** Botão `AC` para resetar os valores e a exibição do visor.
- [x] **Interface Responsiva:** Adaptação dinâmica para telas móbiles e desktops utilizando `clamp()` e Flexbox.
- [x] **Tratamento de Entradas:** Impede a inserção de múltiplos pontos decimais em um mesmo número.

---

## 💻 Tecnologias Utilizadas

- **HTML5** — Estrutura da página[cite: 3].
- **CSS3** — Estilização, layout responsivo e transições de tela.
- **JavaScript (ES6+)** — Lógica do sistema e manipulação de eventos do DOM.
