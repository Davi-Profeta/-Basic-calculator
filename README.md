# Basic-calculator
Uma aplicação web de calculadora simples, intuitiva e totalmente responsiva[cite: 1, 3], focada na manipulação dinâmica do DOM[cite: 2] e estilização com CSS moderno[cite: 1].

---

## 📌 Funcionalidades

- [x] **Operações Matemáticas:** Suporte para adição (`+`), subtração (`-`), multiplicação (`x`) e divisão (`/`)[cite: 2].
- [x] **Limpeza de Tela:** Botão `AC` para resetar os valores e a exibição do visor[cite: 2].
- [x] **Interface Responsiva:** Adaptação dinâmica para telas móbiles e desktops utilizando `clamp()` e Flexbox[cite: 1].
- [x] **Tratamento de Entradas:** Impede a inserção de múltiplos pontos decimais em um mesmo número[cite: 2].

---

## 💻 Tecnologias Utilizadas

- **HTML5** — Estrutura da página[cite: 3].
- **CSS3** — Estilização, layout responsivo e transições de tela[cite: 1].
- **JavaScript (ES6+)** — Lógica do sistema e manipulação de eventos do DOM[cite: 2].
